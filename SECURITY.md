# Security

rootout deletes files and inspects editor extensions, so bugs in it can matter.

- Report a vulnerability privately through GitHub: **Security › Report a vulnerability** on
  https://github.com/shiva2021/rootout. Please do not open a public issue for it.
- Only the latest release is supported. Check `rootout --version` against the Releases page first.
- You should hear back within a week. Fixes ship as a patch release with a CHANGELOG entry.
